# Challenge 13: Kanban Priority Board
**Hard · 50 min.** Build a three-column personal task board.

- Render task cards from local data with todo, doing and done columns.
- Drag a card between columns; update counters and store the board in localStorage.
- Keep the board scrollable horizontally on mobile rather than squashing cards.
- Provide a non-drag fallback control to move each task.
