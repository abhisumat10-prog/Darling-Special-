# Challenge 15: Optimistic Checkout Cart
**Expert · 60 min.** Build a resilient cart for a sustainable home store.

- Quantity buttons update the subtotal immediately while a simulated request resolves.
- A request may fail; restore the previous count and show a clear retry message.
- Validate code WELCOME10 and calculate tax, discount and total.
- Announce cart changes and make removing an item undoable.
