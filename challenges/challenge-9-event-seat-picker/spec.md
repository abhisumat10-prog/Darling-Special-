# Challenge 10: Accessible Event Seat Picker
**Medium · 35 min.** Build a Moonlight Hall theatre map with 24 button seats.

- Available, selected and unavailable states; unavailable seats are disabled.
- Use aria-pressed and precise seat labels. Limit selection to four seats.
- Announce selection and limit feedback through a polite live region.
- Update a $28-per-seat total immediately.
