# Challenge 14: Interactive Energy Telemetry
**Expert · 60 min.** Create an SVG chart for a home battery's energy use.

- Plot supplied hourly data as an SVG line or area with a responsive viewBox.
- Add 24h, 7d and 30d range controls and a keyboard-operable point inspector.
- Tooltip must reveal timestamp, consumption and solar contribution; include a plain-text summary.
- Never use colour alone to distinguish the two data series.
