# Challenge 9: Currency Exchange Widget
**Medium · 30 min.** Build a travel-money quote widget using local USD, EUR, INR and JPY rates.

## Must have
- Labelled amount and currency controls, swap action, 350ms simulated quote loading, and a 1.5% fee.
- Reject empty, zero and negative amounts in an aria-live error.
- Show exchange rate, fee and recipient amount; preserve a usable mobile layout.

**Stretch:** persist the last pair of currencies.
